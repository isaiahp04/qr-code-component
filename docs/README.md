### What I learned

In this challenge, I learned how to center a card by using `<flex>` on the `.card-holder` and setting its height to `743px`.

```html
<div class="card-holder">
  <div class="card">
    <img src="images/image-qr-code.png">
    <div class="container">
    <h4>Improve your front-end skills by building projects</h4>
    <p>Scan the QR code to visit Frontend Mentor and take your coding skills to the next level</p>
  </div>
</div>  
```
```css
.card-holder {
  height: 743px;
  display: flex;
  align-items: center;
  justify-content: center;
}
```
